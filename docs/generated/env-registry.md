## Discipline

- 禁止把后端密钥放进 VITE_*（会被打包进浏览器产物）
- CURSOR_HMAC_KEY / ETAG_HMAC_KEY / SESSION_HMAC_KEY 内置默认值仅允许在非生产环境回落
- ENCRYPTION_KEY_CURRENT 在所有环境必填，无默认值可回落
