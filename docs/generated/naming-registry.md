## Conflicts

| id | conflict | ruling | reason |
| --- | --- | --- | --- |
| N1 | cancelled vs canceled | cancelled | 英式拼写双 l；全仓状态值、CHECK、枚举、文档统一 |
| N2 | expired vs expire | expired | 状态值为过去分词；动词方法名可用 expire |
| N3 | organizationId vs org_id vs organization_id | 三层各自固定：JSON=organizationId、SQL=organization_id、内省 claim=org_id | 新增 claim 禁用缩写；org_id 仅限已发布的内省扩展 claim |
| N4 | challengeId vs mfa_token | challengeId | 全仓清理 mfa_token 字面量 |
| N5 | credentialId vs credId | credentialId | 全仓清理 credId 缩写 |
| N6 | qrcode vs qr-code vs qr_code | URL=qrcode、表名=qr_code_sessions | 不得在 URL 引入连字符变体 |
| N7 | PostgreSQL-first 语义 | PostgreSQL 默认基线（非唯一支持的数据库；第二基线 MySQL，ADR-023） | 禁止表述为"仅支持 PostgreSQL" |
| N8 | 订单 pending vs payment_pending | payment_pending 为合法中间态 | 状态机注册表为唯一口径；CHECK 按其生成 |
| N9 | ADR 状态词 | Current/Target/Open 仅限 docs/adr/ | docs/ 正文一律不使用三态标注 |
| N10 | service account vs SA | 中文服务账号、英文 service account、行文缩写 SA、代码标识符全称 | 代码/表名/JSON 不得使用 SA 缩写 |
| N11 | RateLimit-* vs X-RateLimit-* | 仅 IETF RateLimit-* | 废弃 X-RateLimit-*；Retry-After 仅用于 429/503 |
| N12 | 400 vs 422 分工 | 400 invalid_argument=报文畸形；422 unprocessable_entity=语义校验失败 | 语义校验失败一律 422；错误体 details[].field 携带字段级原因 |
| N13 | 事件名格式 vs 复合事件 | 领域事件 {域}.{对象过去式}；复合事件 {域}.{对象}_{过去式动作} | 新增事件先过命名裁决 |
| N14 | 指标命名 vs 高基数 | Prometheus guliangiam_{域}_{对象}_{单位}；标签仅限白名单 | 禁止用户 ID/组织 ID 等高基数标签 |
| N15 | status vs state 列名 | 统一用 status（含状态机状态与启用/禁用语义） | state 语义偏向状态机内部且与 SQL 保留字冲突；status 通用且 PostgreSQL/MySQL 均允许作为裸标识符；CHECK 约束名统一 ck_{表名}_status |
