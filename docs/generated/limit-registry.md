## Response Headers

- **RateLimit-Limit**:
  - **type**: integer
  - **semantics**: 窗口内可见上限 = max(Quota, Burst)
  - **note**: 令牌桶允许瞬时突刺；Limit < Remaining 会出错
- **RateLimit-Remaining**:
  - **type**: integer_non_negative
  - **semantics**: 当前剩余额度；0 表示已耗尽
- **RateLimit-Reset**:
  - **type**: integer_seconds
  - **semantics**: 距额度恢复的相对时长；向上取整，最小 1
- **RateLimit-Policy**:
  - **type**: string
  - **format**: {quota};w={seconds}[;burst={n}][;comment="{policy_id}"]
  - **note**: comment 用作机器可读策略 id（非 RFC 原意的人类备注）；严格按 RFC 解析的客户端会忽略
- **Retry-After**:
  - **type**: integer_seconds
  - **only_on**: `429`
  - **forbidden**: 禁止写 Go 时长字符串（如 1s）——客户端解析失败退化为固定间隔重试

## Header Discipline

- **write_on_success**: `true`
- **write_on_rejection**: `true`
- **retry_after_only_on_429**: `true`
- **cors_expose_headers**:
  - RateLimit-Limit
  - RateLimit-Remaining
  - RateLimit-Reset
  - RateLimit-Policy
  - Retry-After
- **rejection_status_code**: `429`
- **discipline_note**:
```text
只在 429 给额度，客户端无法在做满之前主动降速；
重试风暴由 503 触发，禁止用 503 代替 429

```

## Distributed

- **model**: Redis + Lua 令牌桶（ADR-019）
- **dimensions**: per_surface × per_organization × per_ip
- **rate_conversion_note**: 多实例速率按部署规模折算；单实例 rate 不得直接放大
- **failure_mode**: 高风险操作保守拒绝；低风险只读降级到进程内限额
- **calib_status**: 待容量压测标定；压测完成后填入 rate/burst 数字
